Get the app

  1. Open Waggle.dmg and drag Waggle onto the Applications folder next to it.
  2. Open Waggle from Applications. macOS asks once to confirm an app downloaded from the internet: choose Open.

Or let Claude Code install it

Install the Waggle Mac app: download https://github.com/limone-eth/waggle-releases/releases/latest/download/Waggle.zip, unzip it into ~/Applications, and open it.
2

Connect your agent

When you open Waggle, its setup walks you through this in the app: press Connect next to each agent you use. One is enough. After that, one step happens outside Waggle:

  • Claude app and Cowork: quit the Claude app and open it again. It loads Waggle only when it starts.
  • Claude Code: start a new session.
  • Codex: type /hooks once and trust the Waggle hooks.
3

Send your first request

Send this to your agent. The first time, it asks permission to use Waggle: choose Always allow. Then a notification appears: open the request, pick one, and press Send.

Try Waggle: write two short subject lines for a launch email, A plain and B playful, and ask me in Waggle which one to use.
Open in the Claude app
In the Claude app and Cowork, answer within about a minute and Claude picks it up by itself. Later than that, Claude has stopped waiting: Waggle shows Claude is not checking with Copy reply. Paste that line into the chat and Claude continues.
