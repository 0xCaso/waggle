# Waggle 0.2.8

- **Signed and notarized by Apple.** macOS now keeps Waggle's permissions across updates, and the first open needs no right-click.
- **No more Desktop access prompt.** Waggle no longer looks inside your project folders. Your agent reads what Waggle needs.
- **Typing is fast again** in the reply box, also on long plans.
- **Hand cursor** on everything you can click.
- **Working shows motion.** The Working chip on Home pulses, like a working request.
- Settings › Agents no longer lists sessions.
- Fixed: "Waggle could not update its Codex plugin" when Codex is installed through nvm.
