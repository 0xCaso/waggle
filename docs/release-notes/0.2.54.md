# Waggle 0.2.54

- **Faster ask pages.** A case with a long write-up beside the question opens much faster. The page no longer measures the whole write-up to split the two columns.
- **Smoother scrolling and typing.** The ask text, its source pills and the scroll position no longer make the whole page redraw.
- **"Ask for" row.** The row shows as many options as fit, and never shows "…" by itself.
- **Session list.** The list redraws only when your sessions change, and the time in the footer keeps moving while Waggle reconnects.

Thanks to @0xCaso for this work (PR #1).
