# Knock 0.1.16

*Your agents knock before they ship. Defuse the slop before it lands.*

**Know when a new version is ready**

- **Update toast.** When a new version of Knock is downloaded, a small card in the bottom-right corner says so, with Restart now, Later and What's new. You'll see it from the next update on.
- **No more empty box.** On an answered ask, the "Delivered" banner now scrolls with the ask, so nothing slides underneath it.

**After updating:** nothing to do.
