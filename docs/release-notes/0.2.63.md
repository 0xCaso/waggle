# Waggle 0.2.63

- **Continue when the session ended.** If the agent's session ended before your reply reached it, the case now says so and offers Continue in a new session. One click starts a new session that picks up the case. The old reply then reads as handed over, not failed.
- **Reply box first.** The Ask for chips now sit in one row right above the reply box. When they do not all fit, the row scrolls sideways, so none of them is hidden.
- **New quick replies.** Let's discuss, Look at my comments and Show me more replace Go ahead.
- **Ask less (optional).** A new Settings page lets the agent decide small things for you: naming, wording, formatting or test choices. It is off until you turn it on. Each answer goes in a folded "Decided for you" list in the queue, and Change my mind brings the ask back to you. Reviews and asks with no recommendation always come to you.
- **Compare (optional).** A screenshot with an earlier version has a Compare switch. Turn it on to see Before and After side by side or with a slider. Show what changed marks the parts that differ.
- **Clearer errors for agents.** When a Waggle tool call fails, the agent gets a clear error code and a true reason, so it can fix the call.
