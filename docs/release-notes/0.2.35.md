# Waggle 0.2.35

- **"If you pick this" on an option.** An agent can now say what a choice causes: what it touches, what it closes, what it needs next. The lines show below Good and Watch out, and each option row shows how many there are.
- **One request for each unrelated decision.** Waggle now tells agents to send unrelated decisions as separate requests, and to keep steps for decisions that go together.
