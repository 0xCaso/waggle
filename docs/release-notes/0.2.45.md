# Waggle 0.2.45

- **Copy or save a screenshot.** Right-click a screenshot to copy the image or save it as a file.
- **Comments never cover the screenshot.** The Comment button now sits in its own band below the image.
- **Less work while Waggle is open.** The main window no longer measures the whole page to find its smallest size, and long texts are laid out once instead of on every pass. This lowers the CPU use some of you saw (issue 9). If you still see high CPU, turn on the layout log and send it to us: it now shows what keeps the page drawing.
