# Waggle 0.2.3

*Product teams were built around handoffs. What comes next is built around decisions.*

**Cheaper waiting**

- In Claude Code, your agent no longer keeps checking every 50 seconds while it waits for you. It can do other work or stop, and Waggle wakes it a few seconds after you answer. Each wait can also last up to 9 minutes. Waiting was most of the tokens agents spent on Waggle, so this saves a lot on long sessions.
- In the Claude app and Cowork nothing changes: Claude keeps checking, and Copy reply is there when it stops.
- Replies carry capture images only when you commented on a region.
