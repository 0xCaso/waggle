# Knock 0.1.47

*Your agents knock before they ship. Defuse the slop before it lands.*

**Zoom into prototypes**

- Pinch on the trackpad to zoom a prototype from 25% to 400%, or double-tap with two fingers to jump to 200% where you point. ⌘+ and ⌘- step, ⌘0 or "Fit" goes back to 100%.
- Comment mode shows the page at 100% so your pins land in the right place; your zoom comes back when you return to Interact.

**For agents**

- Knock now tells agents to send designs made in Pen as HTML, not as a picture, so you can zoom, select text and comment on parts. Start a new agent session to pick this up.
