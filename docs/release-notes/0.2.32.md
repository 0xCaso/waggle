# Waggle 0.2.32

- **Only the artifacts of this round.** A plan with many rounds showed a tab for every artifact it ever had. It now shows the artifacts of the round on screen, plus an older one that an option points to. To see earlier ones, open an answered round and press "See v…".
- **The artifact box keeps its place.** Many tabs could push the artifact box under the sidebar and the answer pane. The tabs now scroll sideways when they do not fit.
