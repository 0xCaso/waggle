# Knock 0.1.30

*Your agents knock before they ship. Defuse the slop before it lands.*

**Comment right on the page**

- **Pins with numbers, notes in place.** On a prototype or a screenshot, each comment is a numbered pin. Hover it to read the note; click it to edit or delete it right there. Comments are numbered 1, 2, 3 across the whole ask, and every pin stays on the page, even the ones you made further down.
- **The Question tab stays open while you comment.** The Comments tab lists them all; click one to jump to its pin. Your reply still sends them all.

**A reply box that grows**

- **Write as much as you need.** The reply field grows as you type, up to about six lines, then scrolls. Return sends, Shift+Return starts a new line. Send is the arrow on the right, and ⌘D still accepts the recommendation.

**Fixed**

- **"Waiting on it" counts only what is really waiting.** The sessions panel counted every ask you had ever answered in a session. It now counts only replies the agent has not picked up yet, or is still working on.
- **The update card waits for you.** "A new version is ready" stays until you click "Restart now" or "Later". Knock no longer shows Sparkle's own update window for scheduled checks.

**After updating:** nothing to do.
