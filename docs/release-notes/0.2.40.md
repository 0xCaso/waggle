# Waggle 0.2.40

- **Ask for more detail in one click.** The last row of the options now reads "Ask for" with a pill for each thing you can get back: the trade-offs, a prototype, screenshots, the numbers, an example, a diagram. One click sends the request. The "?" key and the three dots still open the full list.
- **Your agent hears every reply.** When you answered twice in a short time, the second answer could wait until you wrote to the agent yourself. Waggle now wakes the agent for each answer, also when it has helpers at work in the background.
