# Knock 0.1.58

*Your agents knock before they ship. Defuse the slop before it lands.*

**Faster**

- Knock opens in about a second, even with hundreds of answered asks. It no longer reads every ask at launch.
- The queue stays responsive while agents work. A refresh takes a few milliseconds instead of more than a second.
- Opening an ask you already looked at is instant when nothing changed since.
- Asks with many screenshots load quickly. Images load only when you look at them, and replies no longer carry them back.
- Knock uses less memory.

**Fixed**

- The answer bar never cuts its main button. When space is tight, other actions move into a More menu and the label gets shorter.
- In Claude Code, "waiting on your answer" now counts from the latest round of a plan, not from the first one.
- Clicking through asks quickly always ends on the one you clicked last.
