# Waggle 0.2.33

- **The artifact follows the decision.** When you move to the next decision of a request, Waggle now shows the artifact or the screenshot that belongs to it. Before, a set of screenshots stayed on the first one.
- **Approve with changes.** Pick an option and type a note: the button now reads "Approve with changes" (or "Decide with changes" for a choice that is not an approval). The agent receives your note as changes it must apply before it continues, and it does not ask for the same approval again.
- **Comment on the words of a request.** Select words in the title, what I need, the why, a question, the recommendation or a source. Press Comment (or C), write a note, and it goes to the agent with your reply.
- **Sources on a request.** An agent can now say where a claim comes from: a file, a query, a test run, something you said. Each source shows as a small pill beside the sentence. Hover it for the detail, click to keep it open, or press "Sources" for the full list. Waggle marks a source "Seen by Waggle" when it finds the matching step in the session, and "Assumption" when the agent did not check.
- **A reply no longer fails with "Internal error".** A comment that was already sent could come back in a later round and block the reply. Waggle now sends the rest, and sent comments stay with their round.
