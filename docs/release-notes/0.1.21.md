# Knock 0.1.21

*Your agents knock before they ship. Defuse the slop before it lands.*

**Sounds and more settings**

- **Notification sounds.** Pick a simple sound for new asks in Settings, Notifications, and hear it before you choose. The default is None. You can also hide the question text in notifications and get a reminder after 15 minutes if an ask is still waiting.
- **Agents.** Reconnect a connected agent from Settings, Agents.
- **Previews.** Choose whether Knock asks before opening a link from a preview.
- **Updates.** Turn automatic downloads and the update toast on or off, and see if you're up to date.
- **Data & privacy.** See how many answered asks Knock keeps and clear them. Asks that still need you are never removed.
- **Help.** Copy diagnostics to share when something goes wrong.
