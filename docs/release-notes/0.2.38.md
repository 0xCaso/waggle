# Waggle 0.2.38

- **A quiet pulse.** The pulse of a working session made the window redraw on each frame, which cost about 15% CPU all the time. It now costs almost nothing.
- **Less work on a request page.** A text is measured one time for each width, and a position change no longer starts a new layout. This should help the people who saw the app stay busy with a request open; we are still confirming it with them.
