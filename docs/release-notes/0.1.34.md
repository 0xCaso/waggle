# Knock 0.1.34

*Your agents knock before they ship. Defuse the slop before it lands.*

**Clearer folding**

- **The column's fold button sits right above the column.** On every ask, the button that folds the right column (the question, or the conversation) is in the header, on the column's side of the dividing line, so it is clear what it folds.
- **Only when there is something to fold.** A text ask with no conversation yet shows no conversation column and no fold button. It appears once there is a reply. The queue's button hides when the queue is empty.

**Fixed**

- **The question column fits its content.** On prototype and screenshots asks, the question no longer sits in a wide column with empty space on both sides.
- **The title stays readable on smaller windows.** When space is short, the arrival details drop first, not the title.
- **Setup stays closed after updates.** The setup window no longer reopens by itself when Knock restarts after an update.

**After updating:** nothing to do.
