# Knock 0.1.8

*Your agents knock before they ship. Defuse the slop before it lands.*

**Read more, pick less, see who's connected**

- **Unpick an option.** Click a picked option again to clear it, then send just a comment.
- **Read write-ups right in the ask.** Markdown write-ups and HTML plans now open at full width in the ask, not in a small preview. Prototypes on review asks keep their preview and "Open review".
- **No more answers stuck on "Waiting for pickup".** When an agent sends a clearer version of an ask, the old one goes away. If you had already answered it, the agent gets that answer. An answer the agent can no longer pick up says "Not picked up · the agent's session ended".
- **See which agents are connected.** Settings shows each connected Claude Code or Codex session, and `knock doctor` lists them too. The install guide has a fix for "my agent says Knock is unavailable".
- **Faster switching.** Clicking an ask in the list shows it at once.

**After updating:** restart any Claude Code or Codex session that was open before.
