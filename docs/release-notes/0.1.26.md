# Knock 0.1.26

*Your agents knock before they ship. Defuse the slop before it lands.*

**A lighter status**

- **Pixel status instead of orbs.** Every agent now shows a tiny grid of squares, a label and a live timer. The colour says whose turn it is and the pattern says what the agent is doing: still and red while it waits for you, a slow dotted wave until your reply is picked up, a wave while it works, a light running round the edge while it writes the detail you asked for. The timer says for how long.
- **The ask you have open** shows one status line under its header, for example "Claude Code is working on your reply 1m 12.4s".
- **No more spinners.** Loading a preview, opening a prototype and sending your answer show the same grid with a label and a timer, so a slow step shows it is still moving and for how long.
- Lighter on your Mac than the orbs, and it stops moving when Knock is in the background or Reduce Motion is on.

**Fixed**

- **Replies no agent will pick up** (its session closed, or it moved on to a newer ask) now move to Answered instead of staying in Waiting on agent.

**After updating:** nothing to do.
