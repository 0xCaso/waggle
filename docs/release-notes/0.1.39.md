# Knock 0.1.39

*Your agents knock before they ship. Defuse the slop before it lands.*

**Choose how agents build what they send you**

- **Settings › Artifacts** has three presets. **Quick**: plain pages, text and tables. **Visual** (the default): cards and a chart or two, a preview card, and real screenshots first. **Rich**: interactive prototypes, with React for flows that need it. Agents pick up your choice the next time they read Knock's guide.

**After updating:** pick a preset in Settings › Artifacts if Visual is not what you want, then start a new agent session.
