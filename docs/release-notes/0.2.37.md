# Waggle 0.2.37

- **One decision on each step.** A request with several decisions now shows them one at a time, also when the agent grouped them. The group name stays as a small heading over each step.
- **The artifact follows each decision.** Because each decision has its own step, the artifact of that decision opens with it. Before, a grouped request opened the last artifact sent. If a decision does not link an artifact, Waggle opens the one whose name is in the question.
