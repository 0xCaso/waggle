# Knock 0.1.33

*Your agents knock before they ship. Defuse the slop before it lands.*

**Fold on every ask**

- **Text asks fold too.** The queue and the conversation column have the same panel button as prototypes and screenshots: hover it to see the arrow, click to fold. A folded side leaves a slim rail with its count; click it to bring the side back. ⌘[ and ⌘] work everywhere.

**Fixed**

- **The Dock badge shows.** Knock now asks macOS for permission to badge its icon, so the Needs you count appears on the Dock. If badges are still off, Settings › Notifications says so and opens System Settings for you.

**After updating:** if the Dock badge does not show, open Settings › Notifications in Knock and follow "Open System Settings ›".
