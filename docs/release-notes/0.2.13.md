# Waggle 0.2.13

- **Start from an idea.** Home is now a New idea box: write the idea or drop a document, pick the agent, and start. Working and In planning sessions sit in the sidebar.
- **Asks read like a decision doc.** What the agent needs from you comes first, each answer has its own pros and cons, and attachments open in a box beside the question instead of squeezing it. Earlier asks from the same work are one click away.
- **A page for each project.** Click the project name at the top of an ask to see its asks and the taste themes Waggle learned for it.
- **Questions land in Waggle, not the terminal.** When Claude Code ends a turn with a question, Waggle reminds it to ask you here instead, and it keeps the rule after a long session is compacted. You can turn this off in Settings › Agents, and optionally add a short rule to your CLAUDE.md and AGENTS.md (Codex reads it too).
- **Clearer diagrams.** Agents get a diagram skill for flows and architecture, in your project's own colours and fonts.
