# Knock 0.1.5

*Your agents knock before they ship. Defuse the slop before it lands.*

**Ask for more, see exactly what you sent**

- **Ask for more detail.** Not ready to decide? Press "Ask for more detail", say what would help (or pick "Explain the trade-offs", "Show me a prototype", "Show the numbers"), and the agent answers on the same ask with a write-up, a prototype or a chart.
- **Written explanations.** Agents can attach a Markdown write-up. It reads like the rest of Knock: headings, lists, tables, code. Links open only after you confirm.
- **Follow-ups stay together.** When an agent needs more after your answer, the new ask says "Follow-up to" the earlier one, with a recap of what you chose, and sits right under it.
- **What you sent is what you see.** No option is picked for you anymore. If you type your own answer, that is your answer, shown as "Your answer".
- **Comment mode, fixed.** You can scroll the whole prototype while commenting, pins stay where you put them, and comments from earlier captures never disappear. "You're sending" lists all of them.
- **Plans open full size.** Any ask with a prototype or plan attached opens in the review view, not only reviews.
- **Clearer times.** Every time on an ask shows its date ("Arrived 28 Sep 16:04").
- **Small fixes.** "Change answer" and "Ask for more detail" are real buttons. A row updates the moment you send. Agents keep "why" short and put the details in an attachment.

**After updating:** restart any Claude Code or Codex session that was open before.
