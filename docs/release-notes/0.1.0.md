# Knock 0.1.0

First friend-pilot build.

Knock is a Mac app that shows you the questions and reviews your coding agents send.
Claude Code and Codex agents knock on your door, and every ask lands in one Needs you list. You answer in Knock, and the
agent continues. Everything stays on your Mac.

**Connect Claude Code or Codex.** Install with the steps at https://github.com/limone-eth/knock-releases#install-knock.
The setup window runs `knock install` for the agents you pick. You can connect either or both.

**Updates arrive on their own.** Knock checks once an hour and installs the update when you
quit. You can also press Check for Updates in the app menu or Settings.

**Send feedback.** Tell the friend who shared this build, or open an issue in the releases
repo at https://github.com/limone-eth/knock-releases.
