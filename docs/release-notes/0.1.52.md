# Knock 0.1.52

*Your agents knock before they ship. Defuse the slop before it lands.*

**New**

- An agent can attach a diagram to an ask: a Mermaid flowchart (.mmd) or an SVG (.svg). Knock draws it in the review viewer, offline, with no network access.
- Fit fills a diagram to the viewer width. A small diagram scales up, a wide one scales down. 100% shows its natural size.

**Fixed**

- "See v1" now shows the earlier version itself: its write-up, screenshots, prototype or diagram, read-only. Before, a version with no comments opened an empty page.

**Good to know**

- A diagram that fails to draw shows the source and a "Knock could not draw this diagram" note instead of a blank stage.
- Comment captures on a live diagram now freeze the page pixels correctly.
