# Waggle 0.2.20

- **One format everywhere.** Full size, step-by-step decisions and plans now use the same pick box, option rows and composer as the case page. Before you pick, the recommended option and its reason show in every layout.
- **Answer several questions in full size.** A request with several questions shows its steps, options and "Send N answers" in full size too.
- **Artifacts beside every request.** On a wide window any request with a prototype, write-up or screenshots shows it next to the question, in one artifact box. In full size you can switch between artifacts with tabs and open one in a new window or the browser.
- **Comments on every screen.** Pins and a comment list show on the case page as well as in full size. A comment on a part of a prototype that is not on screen now is listed under "On other views", with Show to go back to it.
- **Clearer rows.** A green check and a red warning sign count the good points and the things to watch. After you answer, the other options stay visible.
- **Cleaner headers.** One crumb with the plain project name, no folder or branch names, and "Why you" on every round.
