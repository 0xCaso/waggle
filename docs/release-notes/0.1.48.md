# Knock 0.1.48

*Your agents knock before they ship. Defuse the slop before it lands.*

**Prototypes behave like a canvas**

- Pinch zooms around your fingers, not from the top-left corner.
- Scroll with two fingers, or hold Space and drag, to move around a zoomed page.
- "Fit" (⌘0) frames the whole page width; ⌘1 goes back to 100%.

**Nudge an agent**

- When an agent has not picked up your answer, press **Nudge**: Knock wakes the Claude Code session and tells it to fetch your reply. "Copy prompt" moved into the "…" menu, and stays the main action for Codex and closed sessions. Works with agent sessions started after this update.

**Fixes**

- If an agent replaces an ask you already answered, it now gets your answer, and the old ask closes instead of waiting forever.
- Dismissing an ask also closes the ask it replaced.
- Agents can keep a Pen design's fonts in its HTML export, offline.
