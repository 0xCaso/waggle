# Knock 0.1.2

*Your agents knock before they ship. Defuse the slop before it lands.*

**Reliability fixes from the first real use**

- **Replies with comments always go through.** Replies that carried a pinned comment could hang on "Sending…". They now send and confirm like any other reply.
- **The queue always loads.** An old unsent reply can no longer leave the list empty. Knock loads your asks first and retries unsent replies quietly in the background.
- **Updates while agents are running are safe.** After an update, Knock's background service always runs the new version, even if a Claude Code or Codex session was open during the update. No more "Internal error".
- **Clear errors.** If something goes wrong, Knock says what happened and suggests `knock doctor`, instead of "Internal error".

**After updating:** restart any Claude Code or Codex session that was open before, so it uses the new connector.
