# Waggle 0.2.16

- **Decisions step by step.** A decision with several questions now shows one question at a time with the usual page, a step bar, Back and Next. You see all your picks at the end and send once. The full document is one click away.
- **Send feedback first.** Type a note or pin comments with nothing answered, and the button says "Send feedback". The agent revises the page and sends a new round; the decision stays open.
- **Calm option cards.** Only the option you pick opens with its pros and cons. Each option shows three clear levels: title, description, and why.
- **The newest round everywhere.** The page, side panel, sidebar row and notification all show the latest round, and the newest artifact version comes to the front.
- **Artifacts no longer vanish.** Clicking between tabs, including a write-up tab, keeps every artifact in reach.
- **Prototypes open full size.** The Open menu also offers a new window or the browser, and images now show in the browser.
- **Comment anywhere.** Comments and element picking work in a new window, full screen and the browser.
- **Flow before screens.** The agent guide now tells agents to plan the user flow before they draw screens.
