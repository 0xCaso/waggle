# Waggle 0.2.28

- **Attach files to a reply.** Use the + in the reply bar, drop files on the request, or paste them. Your agent gets each file's path on this Mac and can read it.
- **One Working list.** Your first job shows on its session row with a "First job" tag, not as a second section.
- **Updates no longer stall.** An agent can add a tab or a message while its request still waits for you.
- **Later rounds replace the first questions.** On a request that started with several questions, your answer goes to the newest round.
- Smaller fixes: an answered request no longer shows twice in the sidebar, and the first tour mark stays clear of your queue.
