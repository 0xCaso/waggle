# Knock 0.1.46

*Your agents knock before they ship. Defuse the slop before it lands.*

**No more missing asks**

- With many asks, Knock could misread the list from its service and keep showing an old queue until something else changed. It now reads in order, tries again when a read fails, and checks the queue once a minute.
- If the queue ever shows fewer asks than the service has, Knock writes it to `logs/queue.log`, so the next problem leaves a trace.
- A follow-up to a follow-up now always shows in the queue.

**Fixes**

- When an agent updates an ask without new options, your first options stay visible as normal answers.
- Settings › Agents can no longer get stuck on "Checking…". After 20 seconds it says "Couldn't check" with a Retry.
