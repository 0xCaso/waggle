# Waggle 0.2.23

- **One way to ask, one way to answer.** Every request now has the same shape: what the agent needs, why, and one or more items to decide. A plain question, a review and a plan step all look and answer the same way, on the request page and in full size.
- **Decide or keep talking.** Pick an answer to decide. Leave a comment, lean to an option or ask something instead, and the agent keeps talking with you before it goes on.
- **Plans as rounds.** Each step of a plan is a new round of the same request, with a small label for where it is (questions, approaches, design, spec).
- **Several files on one request.** An agent can attach more than one artifact to a request; each gets its own tab.
- **Comments on the plan page too.** The artifact beside a plan step takes pins and comments like everywhere else.
- Agents that use the older ways to ask keep working.
