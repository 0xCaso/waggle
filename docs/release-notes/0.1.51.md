# Knock 0.1.51

*Your agents knock before they ship. Defuse the slop before it lands.*

**New**

- After you install the Claude Code plugin, Knock shows a short checklist on Home. It ticks off each step: the plugin is installed, a Claude Code session with the plugin has started, and a test ask has arrived. Copy test prompt gives you a one-line ask to paste into Claude Code, so you can see it work right away.
- Knock now has a Codex plugin too. It brings Knock's ask guidance and hooks that tell Knock what each Codex session is doing. It also keeps a Codex turn open while a Knock ask is still waiting for your answer, so answers get picked up. Knock installs it when you connect Codex. Codex asks you to trust the Knock hooks once: type /hooks in Codex.

**Good to know**

- Codex keeps its usual Knock connection next to the plugin. Nothing changes in how Codex asks you.
