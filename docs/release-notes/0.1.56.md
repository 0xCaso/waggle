# Knock 0.1.56

*Your agents knock before they ship. Defuse the slop before it lands.*

**Fixed**

- Prototypes respond again. Scrolling and clicking inside a prototype work at 100%, with no need to zoom first.
- Replies with many comments on screenshots send fast. Each picture is sent at a smaller size, and you still review it at full size.
- A reply that took a long time to send no longer stays on "Sending your answer". When it reached the agent, Knock now shows it as sent.
