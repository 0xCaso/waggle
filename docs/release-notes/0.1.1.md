# Knock 0.1.1

*Your agents knock before they ship. Defuse the slop before it lands.*

**Fixes from the first installs**

- **Open works.** "Open" in the setup window, "Open Knock" in the menu bar and a notification click now show the main window with the ask, even when no window was open yet. Done does the same.
- **Answer in place.** Options in an ask are clickable. For a question, pick one and press "Send <option>"; "Accept recommendation" is still one key away (⌘D). For a review, your pick carries into the review.
- **See the artifact first.** A review shows a preview of its prototype or screenshot right in the ask. Click it to open the full review.
- **No more Documents prompt.** Knock no longer asks to read your Documents folder. The connector copies what an agent sends, inside the agent's own session.
- **Notifications you can trust.** The setup window and Settings show whether notifications are on, and link to System Settings when they are off.

**After updating:** restart any Claude Code or Codex session that was open before the update, so it uses the new connector.
