# Knock 0.1.3

*Your agents knock before they ship. Defuse the slop before it lands.*

**A real first run, and clearer delivery**

- **New setup.** Connect your agents, then try Knock with your own agent: paste one prompt, answer the ask it sends you, and see it arrive in your terminal. No agent handy? Send yourself a test ask.
- **Agents know how to knock.** Connected agents now get short guidance on when to ask you, when not to, and how to write a good ask. `knock doctor` shows the version.
- **You can see your reply travel.** A spinner shows while your answer waits for the agent to pick it up, then a single "Delivered" line.
- **Dismiss an ask.** Right-click a row, use the "…" menu, or press ⌘⌫. Undo is there for 5 seconds. A waiting agent is told it was dismissed. From the terminal: `knock dismiss --task "<task name>"`.
- **Fix:** screenshots with your comments reached the agent upside down. They now arrive the right way up.

**After updating:** restart any Claude Code or Codex session that was open before, so it gets the new guidance.
