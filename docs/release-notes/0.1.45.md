# Knock 0.1.45

*Your agents knock before they ship. Defuse the slop before it lands.*

**Pick several**

- Agents can ask "pick several": which fixes ship, which screens need another pass. Tick the options you want and send them together ("Send 2"). The agent may set a limit ("pick up to 2"); the rest dim once you reach it. Recommended options arrive ticked, and "Ask for more detail" is still there.

**A home that shows what is going on**

- Click a session under **Right now** to open it in place: its recent asks and your answers. Click one to open it, then **← Home** (or Esc) to come back. Prototype asks have the Home link too.
- Each session now shows what it is about (the task's objective, even for agents running in the background) and what it did last, like "Ran swift test · 20s ago".
- A session that is busy but has not asked anything yet shows **Working**, not Idle.

**Fixes**

- "This session" shows the session's title, not the agent's last message.
- The Offline and Sandboxed badges no longer wrap letter by letter in a narrow column.

**After updating:** start a new agent session so it can send "pick several" asks.
