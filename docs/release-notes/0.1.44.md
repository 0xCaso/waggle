# Knock 0.1.44

*Your agents knock before they ship. Defuse the slop before it lands.*

**New asks come to you**

- If you are looking at an answered ask, or one waiting on its agent, and a new ask arrives (or an ask comes back to you), Knock moves to it.
- It never moves you off an ask that still needs you, and never while you are writing: a reply, a comment, a detail question or a changed answer stay where they are.
