# Knock 0.1.7

*Your agents knock before they ship. Defuse the slop before it lands.*

**Answer reviews faster, see every screen**

- **Answer a review right where you read it.** Review asks now have the reply box in the case pane: pick an option, add a comment, Send. "Open review" is still there when you want to pin comments on the prototype.
- **Several screenshots in one ask.** Agents can send up to 12 screens at once. Flip through them with the thumbnail strip or the arrow keys, and pin comments on each. "You're sending" lists every screen you commented on.
- **Better guidance for agents.** Agents know when to send screens to flip through and when to build one page with screens side by side.

**After updating:** restart any Claude Code or Codex session that was open before.
