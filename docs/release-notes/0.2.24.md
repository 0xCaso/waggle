# Waggle 0.2.24

- **Nothing is decided for you.** A recommended option is only a suggestion until you pick it. Comments or a note on their own send as "keep talking", and Return never sends a decision.
- **Pick any, the same everywhere.** When an agent lets you pick several options, the list uses the same rows as any other request, and nothing is ticked until you tick it.
- **Every item looks like a single question.** A request with several items shows each one with the same rows, the Recommended pill, lean and rule out.
- **Ask from any step.** Type a question on any item of a request and press Ask: the agent gets it right away, with what you answered so far.
- **Flip through screenshots in place.** Move between screens in the request page itself, with arrows, thumbnails and comments on each screen.
- Smaller fixes: one note field per step, clearer activity lines, plain names in the path at the top, and the changes header stays in view when you scroll.
