# Waggle 0.2.12

- **Choose the agent and where it opens.** "Start a new session" has a menu on its button: Claude Code or Codex, in Terminal or in their own app. Waggle remembers your pick, and an app that is not on your Mac shows as "Not on this Mac".
- **Honest replies when an agent's session has closed.** Some hosts, like T3 Code, close an idle Claude Code session after about 30 minutes. Waggle now says so before you answer, marks the request "Session closed", and shows your reply as "Saved · delivers when the agent's session resumes" instead of "Delivery failed". One banner per reply, no Retry that does nothing, and no extra agent turn when the session comes back.
- **Agents in SDK hosts know to ask you to message them** after you answer, so your reply arrives without guesswork.
