# Waggle 0.2.15

- **Pick the agent for one idea.** A chip next to the folder shows which agent starts the idea. Change it for this run only, or tick "Use as my default" to keep it. It turns honey when it differs from your default.
- **A shorter Start menu.** Choose Claude Code or Codex, then where it runs. Places you have not set up fold into one line, and each one links to a card in Settings › Agents with how to get it.
- **Plain titles in the sidebar.** Rows show what the agent is working on (Claude Code's own session title, or a title the agent sends) instead of the folder name. The folder moves to the line below.
- **Decisions, not asks.** The app now calls what your agents send you decisions (and reviews), everywhere you read it.
- **Tidier New idea and sidebar.** The folder chip is outlined so it stands apart from the presets, and every sidebar section uses one header style.
- **The Waggle icon on notifications.** People who updated from Knock saw the old icon on banners. Waggle now fixes this itself after an update (a log out may be needed once).
