# Waggle 0.2.39

- **The right screens in a set.** A request with single screenshots and a set of screens could show the single screenshots in place of the set, and the set was gone in full size. The set now loads in the box and in full size.
- **A fuller usage report.** The usage report on your Mac now also counts how often Waggle is open, the newer screens (setup, Settings, New idea, updates), what happens to each request, and how replies are made: decide or keep talking, the note box, and which row of "Ask for more detail" is used. It still holds numbers only, and nothing is sent: you share the export yourself.
- **Your notes in the export, only if you want.** Settings › Data & privacy has a new switch, off by default: "Include my notes and comments in the export". When it is on, the export file also holds the text of your notes and comments.
