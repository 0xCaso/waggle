# Knock 0.1.50

*Your agents knock before they ship. Defuse the slop before it lands.*

**New**

- Knock now has a Claude Code plugin. It shows when an agent is waiting on you, right above the prompt. It tells Knock what each session is doing. It makes Nudge more reliable. It works in the terminal and in the Code tab of Claude Desktop.
- New users get the plugin during setup.
- If you already use Knock with Claude Code, Knock offers the plugin once on Home. Choose Install plugin to switch. Choose Not now to hide the card.
- You can turn the plugin on or off at any time in Settings > Agents, with the Claude Code plugin switch. Off goes back to the plain connection.

**Good to know**

- The status line needs Claude Code 2.1.287 or later. On older versions, the plugin still connects Knock, but the status line does not show.
- Updating Knock never installs the plugin for you. It only updates a plugin you already have.
