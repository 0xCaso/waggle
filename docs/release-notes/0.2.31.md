# Waggle 0.2.31

- **Region comments always send.** A comment on a region that touches the edge of a screenshot could not be sent, and Retry did not help. It now sends, and a reply saved before this update goes out on Retry.
- **A refused reply says so.** When Waggle refuses a reply, the banner says "Not sent · Waggle refused the reply" with the reason, not "service is offline".
