# Waggle 0.2.11

- **Start from a document, easy to find.** A "+ Start from a document" button sits in the Home header, a row sits at the bottom of the sidebar, and you can drop a file anywhere on the window.
- **The folder chip opens the folder picker**, and the Topic field no longer opens with its text selected.
- **Short titles.** A long request title shows its first sentence as the title and the rest as a description below.
