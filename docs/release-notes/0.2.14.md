# Waggle 0.2.14

- **See the real prototype, not a preview.** A decision shows the agent's prototype live in the page. With several artifacts, each gets a tab, and an option can point at its own variant: select it and Waggle shows it.
- **A cleaner full-size view.** The side panel reads like the decision page: what the agent needs from you, why, and the pros and cons of your pick. The options appear once, next to Decide.
- **Plans you can work on one page.** Each answer to a plan question has its own pros and cons, and the agent's background notes sit folded at the top.
- **One way to start.** Drop a file anywhere on the window to start a New idea with it. New idea can also send your idea to a session that is already running. "Start from a document" is gone.
- **Start in Superset, Conductor or T3 Code.** Pick them in the Start menu, next to Terminal and the Claude and Codex apps.
- **One Working list.** The sidebar shows each running agent once. When it is working on your answer, the row says so, and the "Quiet" row is gone.
- **Know when your answer was used.** An answered decision shows "The agent got it", then "Applied", or says plainly when the agent has not acted on it yet.
- **Asks survive compaction.** When Claude Code compacts a long session, an open ask stays open and the agent picks it up again, with a clear message if it needs to check.
- **Your Requests settings count everywhere.** The optional CLAUDE.md / AGENTS.md rule and the terminal question check now follow what you picked in Settings › Requests.
