# Knock 0.1.43

*Your agents knock before they ship. Defuse the slop before it lands.*

**See what your agents are doing**

- When nothing needs you, "You're all caught up" now lists every connected session under **Right now**: what it is working on, whether it is working, writing to you or idle, for how long, and the last thing you told it. Click a row to open its latest ask.

**Fixes**

- Settings › Agents no longer says "Not installed" while Claude Code or Codex is connected. A tool with live sessions always shows Connected.
- If Knock cannot check a tool, it says "Couldn't check" with a Retry, instead of "Not installed".
- "No new revision" no longer shows on asks that have nothing to look at.
