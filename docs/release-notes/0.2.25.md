# Waggle 0.2.25

- **One look everywhere.** Every request, step and round now uses the same parts: the same header, recommendation card, option rows, keys and composer, in the request page and in full size.
- **Recommendations are a hint, never a pick.** The recommended option has a soft mark. Nothing is selected until you choose.
- **Pick several inside a step.** Check boxes, "Pick up to N", "Tick the recommended" and Clear.
- **You see what the agent said last.** A closing note or a plain message from the agent now shows at the top of the request, with the earlier round folded below.
- **Narrow windows read better.** The question comes first, buttons switch to short labels, and option titles wrap instead of being cut.
- **Request changes works.** With no note yet, it asks what should change.
- **Fewer repeat asks.** Agents no longer re-send a request after each turn when you already answered or asked for their opinion.
