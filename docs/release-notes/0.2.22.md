# Waggle 0.2.22

- **See what changed in a new version.** When an agent sends a new version of a write-up, such as a spec, Waggle marks what changed since the version you last opened. Removed words show in red, new words in green, and a bar marks each changed part. "3 changes since v7" and the up and down buttons take you from one change to the next. You can still comment on any text.
- **Updates ask you on start.** When a new Waggle is out, Waggle tells you when it opens: Install and restart, Later, or Skip this version.
- **No more repeated "access Documents" prompt.** Waggle no longer asks again and again for access to your Documents folder.
