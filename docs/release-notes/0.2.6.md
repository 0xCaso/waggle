# Waggle 0.2.6

- **Simpler list.** Each request is two lines: the question, then where it comes from. Requests are grouped as "Needs you" and "Your agents are on it".
- **Home shows what your agents are doing.** One card per project with its state, the latest artifacts and progress.
- **Off switch.** Pick Off, Things to look at, Look and read or Everything from the menu bar. Running agents hear about the change on their next call.
- **Usage, on your Mac.** Settings › Data & privacy › Usage shows how agents use Waggle and an estimate of the tokens it costs. Export it to a file if you want to share it. Nothing leaves your Mac, and you can turn it off or delete it.
- Shared agent setups: a colleague who has not set up Waggle gets a short note, and their agents ask in the terminal.
