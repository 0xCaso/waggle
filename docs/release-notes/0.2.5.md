# Waggle 0.2.5

*Product teams were built around handoffs. What comes next is built around decisions.*

**Fixed**

- Your answer now reaches the agent after Waggle restarts for an update, or after the agent's session restarts (for example after a login). Before, the reply could fail with "agent session unreachable" and Retry never worked.
- An agent that keeps checking now gets your answer even if the first delivery failed.
- When the agent's session is really gone, Waggle shows Copy reply instead of a Retry that cannot work.
- Restart now tells you when an agent is waiting for your reply.
