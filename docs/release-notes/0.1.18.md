# Knock 0.1.18

*Your agents knock before they ship. Defuse the slop before it lands.*

**Attachments that read as attachments**

- **Write-ups look like documents.** An agent's write-up sits in its own card, clearly apart from "Need from you" and "Why I can't decide", with its reading time. Long ones fold; "Read the whole write-up" opens them in place.
- **Open full size, right where you look.** Every prototype, screenshot and write-up card has an "Open full size" button at the top right.
- **A tidier recommendation.** "Recommended" now sits on its own line above the agent's pick, so long recommendations read cleanly.
