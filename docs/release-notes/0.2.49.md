# Waggle 0.2.49

- **Older versions leave the tabs.** A case now shows only the artifacts of its current round, as plans already did. Earlier versions stay in the version history.
- **One artifact, one name.** Names that differ only by a version word, like "Slide A v2" and "Slide A v3", are now one artifact. Agents are told to keep the same name for a new version.
- **Options work again after "more detail".** When you asked for more detail and the agent answered with a message only, the options stayed locked. Now the page opens again, so you can pick.
