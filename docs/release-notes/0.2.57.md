# Waggle 0.2.57

- **Snip an area.** Press Control Shift W, drag a box anywhere on the screen, add a note, and send it to a live session. Turn it on in Settings › Screenshots. It is off until you turn it on.
- **Start a new session from a screenshot.** The snip panel and both screenshot panels now have a "New session" row. Pick a folder, and Waggle starts your agent there with the image and your note.
- **Only the box you draw.** Waggle uses the macOS crosshair and sees only the area you pick. Esc cancels. macOS may ask you to allow Screen Recording the first time.
