# Knock 0.1.60

*Your agents knock before they ship. Defuse the slop before it lands.*

**New**

- Edit a document in place. On a written explanation, press Edit, change the text, and press Done. Your version becomes the next version, and your reply carries it to the agent with what changed.
- Start from a document. Drop a PRD, a brief or notes on Knock, or use File > Start from a document. Pick what you want (options to decide on, designs in Pen, a prototype, or a review), then send the prompt to a running Claude Code session, start a new one in a folder, or copy it.
- A design kit for all your agents. In Settings > Artifacts, paste or upload your design.md, pick your Pen file and describe your tone. Every agent gets it, unless a project has its own. Agents can also read and update it, and you can undo their changes.
- In the Claude app, Knock now tells you when Claude stopped checking for your answer, with one line to paste so it carries on.
