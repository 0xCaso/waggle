# Waggle 0.2.0

*Product teams were built around handoffs. What comes next is built around decisions.*

**Knock is now Waggle**

- The app, its menus, notifications, Settings and setup say Waggle. What an agent sends you is a request. Agents ask; you decide.
- The agent tools have new names, with the same fields and the same behaviour: `waggle_ask`, `waggle_check`, `waggle_update`, `waggle_guide` and `waggle_settings`. The old `knock_*` names still work for about two weeks, then they go.
- The command is now `waggle` (`waggle doctor`, `waggle install claude`). The old `knock` command still works for about two weeks.
- The Claude Code and Codex plugins are now `waggle@waggle`. The first time you open Waggle after the update, it moves an installed `knock@knock` plugin to `waggle@waggle`, and moves the Waggle entry in the Claude app's settings from `knock` to `waggle`. Each move runs once and leaves a line in `~/Library/Application Support/Knock/logs/migration.log`. If a move fails, Settings > Agents says so. The app still opens.
- The update installs in place. Your data, your notification permission and your settings stay. The folder name `Knock.app` can stay as it is: the app inside is Waggle.

**What you change by hand**

Waggle never edits `~/.claude` for you. If you wrote any of these yourself, change them:

- Claude Code permission allow-lists that name the old tools. Change `mcp__plugin_knock_knock__knock_ask` to `mcp__plugin_waggle_waggle__waggle_ask`. Do the same for `knock_check`, `knock_update`, `knock_guide` and `knock_settings`. Until you do, Claude Code asks you to allow each tool again.
- Your own skills, hooks, fleet tool lists or prompts that call `knock_ask` and the other old names. They keep working for about two weeks. Rename them before then.
- Codex: open `/hooks` once and trust the Waggle hooks. The plugin has a new name, so Codex asks again.
- Claude Code sessions and the Claude app that were already open keep the old entry until you restart them.
- A `knock` link in `~/.local/bin` keeps working. To get the new command, add a link: `ln -sf ~/Applications/Knock.app/Contents/Resources/waggle ~/.local/bin/waggle` (use the real path of your app).
- Links to `Knock.zip` still work. New installs use `Waggle.zip`.
- A Telegram or Slack bot you already set up keeps its old name. Reconnect it in Settings to get the new name.
