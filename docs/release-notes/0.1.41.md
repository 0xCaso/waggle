# Knock 0.1.41

*Your agents knock before they ship. Defuse the slop before it lands.*

**Answers follow the latest update**

- When an agent updates an ask with a new proposal, the answer box now offers the update's options. The first options stay one click away under "First options".
- If an update comes without new options, the reply field comes first, so you are never answering with stale buttons.

**Choose what comes to Knock**

- A new slider in setup and **Settings › Asks**: things to look at, then write-ups and drafts, then quick questions. Keep quick questions (or everything but visuals) in the terminal. The default is Everything, as before.

**Fixes**

- After a comment, Send is ready the moment you press Enter.
- A comment is never lost if the page picture fails; Knock says so instead.
- "You asked" shows the question you asked for more detail on, in full.

**After updating:** start a new agent session so it learns about update options and your new setting.
