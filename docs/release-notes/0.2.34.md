# Waggle 0.2.34

- **A source always shows near the text.** When an agent sends a source but does not cite it in a sentence, Waggle now shows it as a pill at the end of the why text. Waggle also tells the agent to cite each source after the sentence it supports.
- **Source pills line up with the text and are easier to click.** A pill sits on the middle of its line, the pointer becomes a hand over it, and the click area is larger. A click on a pill no longer selects words.
