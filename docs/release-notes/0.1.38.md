# Knock 0.1.38

*Your agents knock before they ship. Defuse the slop before it lands.*

**Options you can read in full**

- **No more cut-off option titles.** When an agent does not give an option a short title, Knock uses a short first phrase if there is one, or shows the whole option, wrapped. The answer box wraps up to three lines instead of ending in "…".

**Richer prototypes, when they need it**

- **The guide now covers bundled React prototypes** for flows with real state, built with the artifacts-builder skill, including the fixes its scripts need on macOS. Plain HTML stays the default.

**After updating:** start a new agent session so it picks up the new guide.
