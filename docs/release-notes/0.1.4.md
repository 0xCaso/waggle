# Knock 0.1.4

*Your agents knock before they ship. Defuse the slop before it lands.*

**Answers you can trust, and a queue you can read**

- **Your answer is locked once the agent has it.** After delivery the ask shows "Your answer", the other options dim, and the review screen shows a green "Delivered" banner instead of a live composer.
- **Change your answer until it is picked up.** While your reply still waits for the agent, press "Change answer". Your earlier comments come back, so you can edit or remove them before you send again. The header then shows "changed" with the time.
- **Rows show what matters.** Each row shows what the agent needs, on one line. Answered rows add your own answer ("you → …") and where it is: waiting for pickup, delivered, or failed with Retry.
- **Real times.** Rows show when an ask arrived ("21:14", "Sat", "12 Sep"), and "took 16m" once you answered. The opened ask shows "Arrived 21:14 · answered 21:30 · took 16m".
- **Newest on top.** Both lists now put the most recent ask first.
- **Small fixes.** The reply field shows its placeholder again. "Send reply" looks like the main button it is. The setup window is cleaner.
