# Knock 0.1.61

*Your agents knock before they ship. Defuse the slop before it lands.*

**New**

- Set up Knock with only the Claude app or Cowork. The first-run Connect step groups Claude Code and the Claude app and Cowork under Claude, like Settings. Any one connection is enough to continue, and Try it gives you a prompt to paste in a chat.
- When an agent's update asks a new question, the question is now the title of the ask, with a Round tag and what you answered before. The update card shows only what changed.

**Better in the Claude app and Cowork**

- Asks show "Claude app" instead of "Claude Code".
- One fallback when Claude stops checking: Copy reply, in both the queue and the ask.
- Claude no longer repeats Knock's writing-style notes to you in the chat.

**Fixed**

- The Remove button for the Claude app in Settings no longer gets squeezed.
