# Waggle 0.2.7

- **No more double asks.** If Waggle restarts while an agent is sending you a question, you now get it once, not twice.
- **Requests in progress pulse.** The dot of a request your agent is working on now moves, so you can see it is going.
- **Usage shows tokens only.** Settings › Data & privacy › Usage lists calls and tokens, without prices.
