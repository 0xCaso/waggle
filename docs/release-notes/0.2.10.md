# Waggle 0.2.10

- **Start from a document, in plain words.** "Screens to look at" works with any tool. "Start a new session" comes first, and "Send to an agent that's already running" lists projects by name. The folder you choose shows as a chip.
- **Readable names everywhere.** Notifications, Telegram and Slack name the project and the agent in plain words, never a worktree or a branch.
- **Better comments.** The note box grows up to 4 lines, arrow keys stay in the text, and a pin on a prototype tells the agent which element it points at.
- **Reload a prototype** with the new button or Cmd+R.
- **Calmer Home.** Only active projects by default; quiet ones are folded. The time shows as a small pill.
- **Dark mode.** Waggle keeps its light look: no more black text boxes.
- **Data & privacy.** "Answered requests" counts and clears every finished ask. Answers an agent is still working with stay.
- **Better prototypes from agents.** Waggle's guide gives agents design rules. Claude Code gets a waggle-prototype skill, and an optional Design helpers card adds Impeccable with one click.
