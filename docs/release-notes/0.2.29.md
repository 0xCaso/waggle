# Waggle 0.2.29

- **A new round opens fresh.** When an agent comes back with a new round on a request you already answered, you can answer it at once. Before, the page kept your last answers and the send button stayed grey.
- **A cleaner reply bar.** The + sits on the same line as your text, and the bar has room above and below.
- **The + opens your files at once.** One click opens the file picker. "Attach files" is now its tooltip.
