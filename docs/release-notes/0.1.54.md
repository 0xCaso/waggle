# Knock 0.1.54

*Your agents knock before they ship. Defuse the slop before it lands.*

**New**

- Comment inline on explanations. Select any text in a write-up, add a note, and the passage stays highlighted with its number in the margin. The agent gets each comment with the exact words you quoted.
- Plan asks. When an agent brainstorms with you, it is one ask that moves through the stages: questions one at a time with its pick ready, then approaches, design sections and the spec. The row shows where the brainstorm is, so it never fills your list with separate asks.
- Done updates. When an agent finishes and only wants to tell you, the ask shows "Done" with a Got it button. It no longer asks you to answer again, and nothing waits on an agent that has already stopped.

**Fixed**

- New asks show up in Needs you right away, even when many updates arrive at once.
