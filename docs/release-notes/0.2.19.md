# Waggle 0.2.19

- **Lean, rule out, or ask.** Not ready to decide? Click the half circle on an option to lean to it, or the × to rule it out. You can lean to several. The button says what you did, like "Lean to 1 and 2, not 3", and the agent answers or revises while the ask stays open. Type with no pick to send a question: the button reads "Ask".
- **Clearer option rows.** The description moved into the hover tooltip, so each row shows just the title. The recommended option has a "✦ Recommended" pill.
- **Conversation on demand.** The conversation column starts closed. Open it from the speech bubble with the round count, next to full screen, or with ⌘].
- **One row per plan.** A plan that needs you shows only in Needs you, with its stage in the line under the title. In planning lists only the plans the agent is working on.
- **Cleaner artifacts.** Screenshots and diagrams inside the artifact box no longer show a second card with its own header, and tab names are never cut.
