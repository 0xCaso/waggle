# Knock 0.1.9

*Your agents knock before they ship. Defuse the slop before it lands.*

**Previews that tell you something, updates that reach your agents**

- **Previews you can read.** A prototype's preview now fills the card at its real size, with no empty bands. Agents can build a small summary card for it (the question, the options side by side, the key number), and phone layouts show in a phone frame.
- **Updates reach open agent sessions.** From now on, when Knock updates, agents that are already running learn about it on their next Knock call and can use what's new without a restart.

**After updating:** restart any Claude Code or Codex session that was open before, one last time. Later updates won't need it.
