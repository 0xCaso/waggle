# Waggle brand: Cell W

A honeycomb cell with a single-line lowercase w, next to the name "waggle" in Inter Tight.

- Mark: `cell-w-mark.svg` (the site favicon). The app icon source is `apps/macos/Resources/AppIcon.svg`.
- Colours: honey 300 `#F9C846`, honey 500 `#F2B01E` (brand), honey 600 `#E89A0C`, ink `#16181A`, Open `#E0352B` (needs a decision), Decided `#18A058`. Honey is a fill, never a text colour.
- Type: Inter Tight, Medium for the name and headings (tracking -3.5%), Regular for UI. JetBrains Mono for meta.
- Notes: `notes/` holds the wordmark, brand-direction and copy notes from the brand exploration (Oct 3, 2026). The full board and the HTML explorations stay in the operator's `waggle-design` folder.
